## 🚀 Featured Projects

### 1. AI Compass — Multi-Agent AI News & Recommendation Platform

- Built an AI-powered platform that collects and processes content from 7 different sources.
- Designed a 5-agent pipeline for content analysis, personalization, and recommendations.
- Led a team of five as Team Lead and Main Developer.
- Implemented personalized recommendations using pgvector similarity, weighted scoring, and MMR diversification.
- Evaluated recommendation quality using offline NDCG@10 and MAP metrics.
- Developed semantic search and a RAG-based chat system using Sentence-Transformer embeddings, PostgreSQL, pgvector, and Groq-served LLMs.
- Integrated Celery and Redis for background processing.

### 2. AynVQA-MSA — Arabic Spoken Visual Question Answering

- Participated in the ImageEval 2026 / ArabicNLP shared task.
- Developed a pipeline combining Whisper transcription, structured parsing, and vision-language models.
- Achieved **79.00% accuracy (395/500)** on the official development split, compared with the organizers' 39.8% baseline.
- Improved performance through a parsing repair step and JSON-schema-constrained decoding.
- Experimented with Chain-of-Thought and few-shot prompting techniques.

### 3. Fitness Activity Tracker

- Developed a wearable-based activity recognition system using accelerometer and gyroscope data.
- Worked on exercise classification and repetition counting.
- Contributed to data preprocessing, feature engineering, and model evaluation as part of a three-person team.
- Applied Chauvenet's criterion for outlier removal, PCA, and FFT-based feature extraction.
- Evaluated five classification algorithms across five feature sets using Grid Search.
- Achieved approximately **99% held-out test accuracy** using Random Forest.
