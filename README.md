## 🚀 Selected Projects

### 01. AI Compass — Multi-Agent AI News & Recommendation Platform

*May 2026 – September 2026*

An AI-powered news platform that collects, enriches, and recommends relevant content through a multi-agent architecture.

**My Contributions & Technical Highlights**

- Led a team of five as Team Lead and Main Developer.
- Designed a 5-agent processing pipeline to enrich content collected from 7 sources.
- Built a personalized recommendation engine using pgvector similarity, weighted scoring, and Maximal Marginal Relevance (MMR) diversification.
- Evaluated recommendation quality using offline NDCG\@10 and MAP metrics.
- Developed semantic search and a RAG-based chat experience using Sentence-Transformer embeddings, PostgreSQL, pgvector, and Groq-served LLMs.
- Integrated Celery and Redis for asynchronous background processing.

**Core Technologies:** Python · LLMs · Multi-Agent Systems · RAG · Sentence Transformers · PostgreSQL · pgvector · Celery · Redis

---

### 02. AynVQA-MSA — Arabic Spoken Visual Question Answering

*July 2026 – August 2026*

A spoken Arabic Visual Question Answering pipeline developed for the ImageEval 2026 / ArabicNLP shared task.

**Technical Highlights**

- Built a pipeline combining Whisper speech transcription, schema-constrained parsing with a repair step, and a vision-language model.
- Achieved **79.00% (395/500)** on the official development split, compared with the organizers' 39.8% baseline.
- Improved an earlier 74.80% result through the parsing repair step.
- Replaced regex-based parsing with JSON-schema-constrained decoding.
- Experimented with Chain-of-Thought and few-shot prompting, evaluating their impact before deciding what to include in the final pipeline.

**Core Technologies:** Python · Whisper · Vision-Language Models · NLP · Structured Outputs · JSON Schema · Prompt Engineering

---

### 03. Fitness Activity Tracker — ML-Powered Exercise Classification

*March 2026 – April 2026*

A wearable-based machine learning system for classifying barbell exercises and counting repetitions using wrist-worn sensor data.

**Technical Highlights**

- Worked in a three-person team on preprocessing, feature engineering, and model evaluation.
- Processed accelerometer and gyroscope data for exercise recognition and repetition counting.
- Applied Chauvenet's criterion for outlier removal, PCA, and FFT-based feature extraction.
- Compared five classification algorithms across five feature sets using Grid Search.
- Achieved approximately **99% held-out test accuracy** using Random Forest.

**Core Technologies:** Python · NumPy · Pandas · Scikit-learn · Random Forest · Feature Engineering · PCA · FFT
