## Featured Projects

### AI Compass — Multi-Agent AI News & Recommendation Platform

AI-powered news platform that ingests content from 7 sources, enriches it through a 5-agent pipeline, and recommends relevant articles to each reader.

- Led a team of five as team lead and main developer.
- Built the recommendation engine using pgvector similarity, weighted scoring, and Maximal Marginal Relevance (MMR) diversification.
- Evaluated recommendations offline using NDCG\@10 and MAP.
- Designed semantic search and RAG chat using Sentence-Transformer embeddings, PostgreSQL/pgvector, and Groq-served LLMs.
- Used Celery and Redis for background processing.

### AynVQA-MSA — Arabic Spoken Visual Question Answering

A spoken Arabic Visual Question Answering pipeline developed for the ImageEval 2026 / ArabicNLP shared task.

- Built a pipeline combining Whisper transcription, schema-constrained parsing with a repair step, and a vision-language model.
- Achieved **79.00% (395/500)** on the official development split, compared with the organizers' **39.8% baseline**.
- Improved an earlier 74.80% result through the parsing repair step.
- Replaced regex parsing with JSON-schema-constrained decoding.
- Tested Chain-of-Thought and few-shot prompting and evaluated whether their gains justified deployment.

### Fitness Activity Tracker — ML-Powered Exercise Classification

A wearable-sensor project that classifies barbell exercises and counts repetitions using wrist-worn accelerometer and gyroscope data.

- Worked in a three-person team on preprocessing, feature engineering, and model evaluation.
- Applied Chauvenet outlier removal, PCA, and FFT-based features.
- Compared five classifiers across five feature sets using grid search.
- Random Forest achieved approximately **99% accuracy** on held-out test data.
